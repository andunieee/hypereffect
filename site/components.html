Components

hypereffect defines eighteen components. Renderers implement all of them. Servers cannot add more.

  2. Value types

  4. Content: text, notice, badge, image, divider, progress
  5. Controls: button, input, checkbox, select, slider

Common attributes

Every element has these attributes. The first four are structural and must be literal values; they cannot be CEL expressions.

AttributeTypeDescription
idstringRequired. Unique within the session.
typestringRequired. One of the component names on this page.
parentstringId of the containing element. Omitted means the element is at the root. See nesting rules.
beforestringId of a sibling to insert before. Omitted means append as the last child (for new elements) or keep the current position (for updates).
visibleboolDefault true. When false the element and its descendants are not shown and take no space.

Value types

Expressions
Any non-structural attribute may be given as {"cel":"…"} instead of a literal. The expression is evaluated against signals and must produce a value of the attribute's type. On error, the attribute takes its default.
Signal paths
The bind attribute is a dot-separated path into the signals, such as "form.email". Each segment matches [A-Za-z_][A-Za-z0-9_]*. A path whose first segment begins with _ is local. Paths are structural and must be literal.
Handlers
Event attributes (onPress, onChange, onSubmit, onDismiss) take a handler object with at least one of:
  • patch — a merge patch applied to the signals locally. Leaf values may be CEL expressions, evaluated before the patch is applied.
  • action — the name of an action to send to the server. May be accompanied by payload (any JSON, literal) and indicator (a local signal path set to true when the action is sent).
If both are present, the patch is applied first and the action carries the patched signals. Handlers are structural.
Enumerations
gap: none · small · medium · large.
align (cross axis): start · center · end · stretch.
justify (main axis): start · center · end · between.
An unknown enumeration value is treated as the default.

Containers

column

Arranges children vertically. The root of the session behaves as a column with default attributes.

AttributeTypeDefaultNotes

row

Arranges children horizontally. Renderers on narrow surfaces may wrap a row even when wrap is false, rather than overflow.

AttributeTypeDefaultNotes

card

A visually grouped region, laid out as a column. Typically drawn with a border or a distinct background.

AttributeTypeDefaultNotes
titlestringnoneShown as a heading for the group.

list

A vertical sequence of items with separators. Each child is one item. Renderers may virtualise long lists.

AttributeTypeDefaultNotes
emptystringnoneText shown when the list has no visible children.

tabs

Shows one of its tab children at a time, with a control to switch between them. Switching is local and does not contact the server unless onChange has an action.

AttributeTypeDefaultNotes
bindpathnoneSignal holding the id of the selected tab. If missing or not the id of a visible child, the first visible tab is shown. Without bind the selection is renderer state.
onChangehandlernoneRuns after the selection changes.

tab

One page of a tabs element, laid out as a column. Its parent must be a tabs.

AttributeTypeDefaultNotes
labelstringthe idShown in the tab control.
gapenummedium

dialog

A modal surface shown above the rest of the interface, laid out as a column. A dialog cannot have a parent. While any dialog is open, the renderer should prevent interaction with elements outside it. If several are open, the most recently opened is on top.

AttributeTypeDefaultNotes
openbooltrue
titlestringnone
onDismisshandlernoneRuns when the user asks to close the dialog (Escape, back gesture, close button). If absent, the dialog cannot be dismissed by the user. The renderer does not close the dialog itself; the handler must change whatever open depends on, or the server must.
 
element {"id":"confirm","type":"dialog","title":"Delete project?",
         "open":{"cel":"has(signals._confirm) && signals._confirm"},
         "onDismiss":{"patch":{"_confirm":false}}}

Controls accept a disabled attribute (bool, default false). A disabled control is shown but cannot be operated and does not run handlers.

A text field. The value is stored in the bound signal: a string, or a number for the number variant (null when the field is empty or does not parse).

Nesting rules

ComponentMay have a parentAccepts children
column, row, card, listyesany component except tab and dialog
tabsyestab only
tabmust be a tabsany component except tab and dialog
dialognoany component except tab and dialog
all othersyesno

An element without a parent is placed at the root, except a tab, which is rejected. There is no limit on nesting depth in the protocol, though renderers may impose one.
