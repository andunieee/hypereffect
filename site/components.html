Components

hypereffect defines eighteen components. Renderers implement all of them. Servers cannot add more.

Containers

column

Arranges children vertically. The root of the session behaves as a column with default attributes. 

element {"id":"col","type":"column"}
element {"id":"a","type":"text","parent":"col","text":"Lorem ipsum"}
element {"id":"b","type":"text","parent":"col","text":"Dolor sit amet"}
Attribute Type Default Notes
id string — Required. Unique within the session. Literal.
type string — Required. Always "column". Literal.
parent string root Id of the containing element. Literal. Must be a column, row, card, list, tab or dialog.
before string last Id of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visible bool true expression When false the element and its descendants are not shown and take no space.
gap enum medium expression none · small · medium · large.
align enum stretch expression start · center · end · stretch. Horizontal alignment of children.

tabs

Shows one of its tab children at a time, with a control to switch between them. Switching is local and does not contact the server unless onChange has an action. 

element {"id":"tabs","type":"tabs"}
element {"id":"a","type":"tab","parent":"tabs","label":"Lorem"}
element {"id":"b","type":"tab","parent":"tabs","label":"Ipsum"}
Attribute Type Default Notes
id string — Required. Unique within the session. Literal.
type string — Required. Always "tabs". Literal.
parent string root Id of the containing element. Literal. Must be a column, row, card, list, tab or dialog.
before string last Id of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visible bool true expression When false the element and its descendants are not shown and take no space.
bind path none Signal holding the id of the selected tab. If missing or not the id of a visible child, the first visible tab is shown. Without bind the selection is renderer state. Literal.
onChange handler none Runs after the selection changes. Literal.

dialog

A modal surface shown above the rest of the interface, laid out as a column. A dialog cannot have a parent. While any dialog is open, the renderer should prevent interaction with elements outside it. If several are open, the most recently opened is on top. 

element {"id":"dialog","type":"dialog","title":"Lorem ipsum"}
element {"id":"a","type":"text","parent":"dialog","text":"Lorem ipsum"}
element {"id":"b","type":"text","parent":"dialog","text":"Dolor sit amet"}
Attribute Type Default Notes
id string — Required. Unique within the session. Literal.
type string — Required. Always "dialog". Literal.
parent string — Not allowed: a dialog is always at the root.
before string last Id of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visible bool true expression When false the element and its descendants are not shown and take no space.
open bool true expression
title string none expression
onDismiss handler none Runs when the user asks to close the dialog (Escape, back gesture, close button). If absent, the dialog cannot be dismissed by the user. The renderer does not close the dialog itself; the handler must change whatever open depends on, or the server must. Literal. 
element {"id":"confirm","type":"dialog","title":"Delete project?",
         "open":{"cel":"has(s._confirm) && s._confirm"},
         "onDismiss":{"patch":{"_confirm":false}}}

input

A text field. The value is stored in the bound signal: a string, or a number for the number variant (null when the field is empty or does not parse). 

element {"id":"input","type":"input","label":"Lorem","placeholder":"Ipsum"}
Attribute Type Default Notes
id string — Required. Unique within the session. Literal.
type string — Required. Always "input". Literal.
parent string root Id of the containing element. Literal. Must be a column, row, card, list, tab or dialog.
before string last Id of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visible bool true expression When false the element and its descendants are not shown and take no space.
disabled bool false expression Shown but cannot be operated, and does not run handlers.
bind path none Without bind the field's value is not observable. Literal.
label string none expression
placeholder string none expression
error string "" expression A validation message. A non-empty value marks the field invalid.
variant enum text expression text · multiline · password · number · email
onChange handler none Runs when the user has finished an edit: on losing focus, or after a short idle period chosen by the renderer. Not on every keystroke. Literal.
onSubmit handler none Runs when the user confirms (Enter in a single-line field). Not available for multiline. Literal. 
element {"id":"email","type":"input","parent":"form","label":"Email","variant":"email",
         "bind":"form.email","error":{"cel":"has(s.errors.email) ? s.errors.email : ''"}}
