Components

hypereffect defines eighteen components. Renderers implement all of them. Servers cannot add more.

Containers

column

Arranges children vertically. The root of the session behaves as a column with default attributes.

element {"id":"col","type":"column"}
element {"id":"a","type":"text","parent":"col","text":"Lorem ipsum"}
element {"id":"b","type":"text","parent":"col","text":"Dolor sit amet"}
AttributeTypeDefaultNotes
idstring—Required. Unique within the session. Literal.
typestring—Required. Always "column".
parentstringrootId of the containing element. Literal. See nesting rules.
beforestringlastId of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visiblebooltrueWhen false the element and its descendants are not shown and take no space.
gapenummedium
alignenumstretchHorizontal alignment of children.

tabs

Shows one of its tab children at a time, with a control to switch between them. Switching is local and does not contact the server unless onChange has an action.

element {"id":"tabs","type":"tabs"}

AttributeTypeDefaultNotes
idstring—Required. Unique within the session. Literal.
typestring—Required. Always "tabs".

dialog

A modal surface shown above the rest of the interface, laid out as a column. A dialog cannot have a parent. While any dialog is open, the renderer should prevent interaction with elements outside it. If several are open, the most recently opened is on top.

element {"id":"dialog","type":"dialog","title":"Lorem ipsum"}
element {"id":"a","type":"text","parent":"dialog","text":"Lorem ipsum"}
element {"id":"b","type":"text","parent":"dialog","text":"Dolor sit amet"}
AttributeTypeDefaultNotes
idstring—Required. Unique within the session. Literal.
typestring—Required. Always "dialog".
parentstring—Not allowed: a dialog is always at the root.
beforestringlastId of a sibling to insert before. Omitted means append (new elements) or keep the current position (updates). Literal.
visiblebooltrueWhen false the element and its descendants are not shown and take no space.
openbooltrue
titlestringnone
onDismisshandlernoneRuns when the user asks to close the dialog (Escape, back gesture, close button). If absent, the dialog cannot be dismissed by the user. The renderer does not close the dialog itself; the handler must change whatever open depends on, or the server must.
 
element {"id":"confirm","type":"dialog","title":"Delete project?",
         "open":{"cel":"has(signals._confirm) && signals._confirm"},
         "onDismiss":{"patch":{"_confirm":false}}}

Nesting rules

ComponentMay have a parentAccepts children
column, row, card, listyesany component except tab and dialog
tabsyestab only
tabmust be a tabsany component except tab and dialog
dialognoany component except tab and dialog
all othersyesno

An element without a parent is placed at the root, except a tab, which is rejected. There is no limit on nesting depth in the protocol, though renderers may impose one.
